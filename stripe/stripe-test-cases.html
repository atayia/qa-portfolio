Charges API

POST TC-CH-001 — Create Charge — Valid Token
Endpoint
POST /v1/charges
Objective
Verify a charge is created and immediately captured with a valid card token.
Linked Requirement
REQ-STR-03
Request Body
{
  "amount": 1500,
  "currency": "usd",
  "source": "tok_visa",
  "description": "TC-CH-001 test charge"
}
Expected Result
HTTP 200 • status: "succeeded" • paid: true • amount: 1500
Actual Result
HTTP 400 · Card Token usage on the Charges API has reached end of life. Stripe requires migration to the Payment Intents and Payment Methods API.
Status
Blocked
Notes
Blocked by Stripe's Card Token EOL policy. Policy re-enable attempted via Stripe Dashboard API settings and key regeneration — error persisted. Charge creation verified via PaymentIntents in TC-PI-001. See STR-OBS-001.
Evidence

Response — 400 Card Token EOL
