Automation Overview

Manual test cases from v1 were extended with Postman pm.test() and pm.expect() assertions, automating response verification for all in-scope test cases. Each request is structured as a standalone test case with its own body, scripts, and saved example response.

TC-RF-003 (Double Refund Attempt) was discovered during automation execution — not part of the original manual scope. Demonstrates exploratory testing instinct during automation runs.
